# 🚀 Action Module 05: `AC05_Matrix-AutoTile.sh`

## 🎯 Objective
This script implements the **3D Matrix / AutoTile Layout**, often referred to as the "Fibonacci" or "Spiral" layout.
It recursively divides the available screen space:
1.  **First Window:** Takes the primary half (determined by `MASTER_RATIO`).
2.  **Second Window:** Takes the top half of the remaining space.
3.  **Third Window:** Takes the left half of the remaining quarter...
4.  **And so on:** Alternating horizontal and vertical splits deep into the spiral.

This layout optimizes screen real estate for large numbers of windows, keeping the most important (Master) window large while neatly stacking secondary windows.

---

## 🛠️ Key Features and Logic

| # | Feature | Detail |
| :--- | :--- | :--- |
| 1 | **Recursive Fibonacci Algorithm** | Uses a recursive function (`recursive_fibonacci`) to calculate geometry. It dynamically switches split direction (Vertical → Horizontal) at each depth level. |
| 2 | **Matrix Data Preference** | Prioritizes the `MATRIX_3D` variables generated by **M07**. This ensures the visual structure matches the abstract blueprint perfectly. |
| 3 | **Min-Size Constraints** | Checks both `MIN_WIDTH` and `MIN_HEIGHT` at every recursion step. If a calculated split is too small for a window, it forces the window to its minimum size, potentially overlapping slightly to prevent application breakage. |
| 4 | **Geometry Patching (Terminals)** | Includes pixel-perfect adjustments (`-16px` width, `-32px` height) for `xfce4-terminal` to compensate for grid sizing issues. |

### 3️⃣ The Recursive Fibonacci Logic
This is the core engine. It takes a bounding box (`R_X`, `R_Y`, `R_W`, `R_H`) and a list of windows.

```bash
recursive_fibonacci() {
    # ... inputs ...
    
    # BASE CASE: Only 1 window left? Give it the remaining space.
    if [ "$R_COUNT" -eq 1 ]; then
        echo "${CURRENT_WID}:${FINAL_X},${FINAL_Y},${VISUAL_W},${VISUAL_H}"
        return
    fi
    
    # RECURSIVE STEP: Split and dive deeper.
    if [ "$R_DIR" -eq 0 ]; then
        # Vertical Split (Master Left, Remaining Right)
        # Recurse into the RIGHT side with Horizontal Split direction (1)
        recursive_fibonacci ... 1 ...
    else
        # Horizontal Split (Master Top, Remaining Bottom)
        # Recurse into the BOTTOM side with Vertical Split direction (0)
        recursive_fibonacci ... 0 ...
    fi
}
```
